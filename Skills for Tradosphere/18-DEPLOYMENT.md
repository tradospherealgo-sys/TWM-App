# Deployment / Release Team

Audit:
- production env
- Vercel/deployment config
- env vars
- domain/HTTPS
- build/runtime
- DB connectivity
- external APIs
- production-only failures
- source vs production version

Before release:
- approved scope
- tests pass
- no secrets committed
- production env verified
- rollback/checkpoint available

After release:
- smoke test critical flows
- auth
- real production data
- integrations
- branding.
